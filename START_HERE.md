## 🚀 5-Minute Setup

```bash
# 1. Go to mobile app folder
cd mobile-app

# 2. Install dependencies
npm install

# 3. Setup environment
cp .env.example .env.local

# 4. Add your API keys to .env.local
# - EXPO_PUBLIC_GOOGLE_GEMINI_API_KEY
# - EXPO_PUBLIC_VAPI_PUBLIC_KEY
# - etc.

# 5. Start development
npm start
```
